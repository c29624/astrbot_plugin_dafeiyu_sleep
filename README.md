# astrbot_plugin_dafeiyu_sleep

> 大肥鱼的真实作息——到点真睡（全渠道静默零 token），早上真醒（知道昨晚几点睡的、读过夜里谁说了什么）。

给 AstrBot 机器人一套**真实的随机睡眠作息**：每晚自动抽签入睡/起床时刻，睡着期间私聊、群聊、@、戳一戳全部静默（零模型调用），消息进按会话隔离的夜间缓冲；早上醒来把夜间消息注入对话历史（长期记忆可留痕），并用临时注入告诉她"昨晚几点睡的、收到几条"。

## 和同类方案怎么选（差异说明）

作息/静默类插件常见三种做法，路线不同挑适合你的：

| 路线 | 作息从哪来 | 适合谁 |
|---|---|---|
| 手动开关类 | 发指令让她静音/醒来 | 想自己安排她作息的 |
| 固定时段类 | 配置每晚固定时段静默 | 想要规律、可预期的 |
| 剧情生成类 | 让大模型每天编一张日程表 | 想看"虚拟生活"演出的 |
| **本插件：机制抽签** | 每晚真实掷骰抽作息，底层参数全可调 | 想要"她自己活的作息"的 |

本插件做得比较深的地方（同类方案里没见过的）：

- **真随机作息**：入睡/起床每天重新抽签（近正态 + 失眠夜 + 赖床掷骰 + 睡眠债 + 周末加成 + 大小周/法定节假日/调休），重启不重抽——连续观察一周也拟合不出她的闹钟
- **夜间消息不丢也不吵**：睡着全渠道静默零 token，消息进按会话隔离的缓冲；**晨间冲刷**把夜间消息本体喂进对话历史（长期记忆可留痕）——她早上真的"翻手机"，不是失忆
- **临时清醒 → 智能回睡**：被叫醒后真聊，冷场了自己回去睡，睡眠债记账次日多睡
- **梦话**：睡着被戳按概率嘟囔一句，零 token
- **状态开放**：配套的主动私聊类插件直接读本插件作息状态——她睡着绝不主动发消息，一套拼出完整真实感

坦白讲：只想要"每晚 0 点到 8 点别说话"的话，固定时段类一个配置项就够；本插件的全部复杂度，都花在"作息经得起观察"这一件事上。

### v0.8.1 无声溜走档位门控 + 晨间补话

- **无声从几档起可能**（`sleep_sneak_silent_tier`，轻/中/重/从不，默认**中**）：她困到"哈欠连串话说不利索"及以上，才可能**聊着聊着直接睡着不吭声**（概率仍是嘟囔比例的补集）；更清醒时溜走必定打招呼——真人只有真断片才会无声，轻困就消失像掉线不像睡着。选"从不"=永远打招呼。
- **晨间补话**：无声睡着的第二天，她会在早上自然提一句"昨晚跟你聊着聊着就睡着了，你后面说的我早上才看到"（真人无声睡着的补偿就是这个解释）；配主动私聊 ≥2.5.1 时，留言回应线会代提并在冲刷时消耗标记，不会说两遍。隔天未提的标记自动过期（人家第二天都没来，再提就尬了）。

### v0.8.0 陪聊熬夜三件套

- **到点还想聊就陪**（`sleep_grace_on`，默认开）：到睡觉点 TA 还在私聊 → 不硬走，继续陪，直到**冷场**（TA 每夜随机 5~8 分钟没回）才**偷偷溜走**（`sleep_sneak_ratio`% 留一句困迷糊的嘟囔；无声只在困到设定档位后可能，见 0.8.1）；最多陪 4 小时硬顶，到顶必留一句断片式的话再睡。宽限关=到点就睡（不陪了，但道个别再睡——不会硬切消失）。守门/缓冲/晨间冲刷/梦话/作息表全部照常，这个开关只管"陪不陪"。
- **困意三档爬坡**：陪聊期间她随时间**轻→中→重**爬坡（升档间隔每夜随机 30/45/60 分钟，后段必到重档），每轮对话带画面体状态行（轻=眼皮沉反应慢半拍，可以提一嘴困也可以不提；中=哈欠连串、话变短、开始冒"好想睡觉"；重=意识断续、句子碎成几个字、嘴硬的也扛不住承认"特别特别想睡"）——溜走时她真的困得话说不利索，入睡水到渠成。失眠夜直接中档起。
- **熬夜记不记仇**（`sleep_stayup_cost_on`，默认开）：陪聊时长进 7 天滚动账本，开着=次日真有后遗症——分级事实行（晚 45 分钟=有点困 / 1 小时=很困 / 4 小时=通宵硬撑）、午睡概率每 2 小时亏空 +10%、午睡能抵掉 40% 亏空、当晚起睡前移（熬夜×0.5 钳 90 分钟）、**亏空越多当晚陪聊额度越小**（<3h→4h / 3~6h→1.5h / 6~10h→半小时 / ≥10h→不陪）；关=当晚照演困意、次日没事人（账本照记随窗口淡出）。休息日补觉总量钳 180 分钟。`/睡觉状态` 可查账本。
- **dm 代答留言**（配主动私聊 v2.5.0）：TA 睡前留言 → 她醒后主动私聊插件必发"刚醒看到留言"回应并写标记文件 → 本插件冲刷前见标记**跳过表演**（防她回完再演一遍翻未读），留言原文随她的回应归档。

## 已实现的行为

- **随机作息生成器**（每天自动抽签，即"昨晚几点睡"的真实数据源）：
  - 入睡：以基准 23:00 为中心近正态波动，硬边界 22:15~01:10；10% 概率失眠夜（拖到 01:10~02:30，且次日必赖床）
  - 起床：`clamp(入睡 + 抽样时长(7.5h±1h) + 周末加成(+30~90min，按起床日判) + 睡眠债 + 赖床加成, 06:40, 09:30)`
  - 赖床掷骰：入睡晚于 00:30 → 基础 50% 概率，每再晚 30 分钟 +15%（封顶 100%）；早睡也有 10% 偶发；命中 +10~40 分钟
  - 抽签结果持久化：AstrBot 重启**不重抽**，跨日自动滚动新作息
- **睡眠守门（fail-open）**：priority=maxsize-10 先于所有常规插件；睡着期间全渠道截停入缓冲，任何异常=放行+ERROR（宁可半夜穿帮一句，不可凌晨哑巴到中午）
- **夜间缓冲**：按会话严格隔离（群 A 的夜里绝不串到群 B / 私聊），单会话 50 条/总量 500 条超限丢最旧+截断标记，落盘重启不丢
- **晨间冲刷双通道**：夜间消息本体走消息链拼接**进对话历史**（LivingMemory 等反思引擎可读 → 长期记忆留痕）；作息事实行走 `extra_user_content_parts(mark_as_temp)` 不入历史（保前缀缓存）
- **指令豁免**：`/` 开头指令睡眠期照常执行（放歌、重置等不受影响）
- **叫醒频道**（白天"@必回"的夜间版）：
  - 私聊：消息以叫醒前缀任一项开头（默认 `醒醒啦`/`醒醒`/`!`，可增删改，清空=禁用）
  - 群聊：@她 **+** 叫醒词双条件缺一不可（默认 醒来/醒醒/起来啦/起床啦/别睡啦；仅@不算）
  - 权限：默认仅白名单/管理员可叫醒（白名单默认=AstrBot 管理员名单）；可关成任何人都能叫醒；无权限的叫醒=静默入队不解释
  - 叫醒即冲刷：叫醒来源会话的积压消息随叫醒请求一起注入（她被摇醒顺手翻未读）；其他会话不动
  - 演出：注入"你被强行叫醒，现在半梦半醒"（迷糊/起床气由人设发挥）；午睡被叫醒=直接转清醒、轻度迷糊无起床气
- **梦话**：睡眠期被戳（私聊、群里@她、戳一戳）时按概率回一句可配置的梦话（默认 `Zzz…`/`呼……zzz…`/`（翻了个身继续睡）` 等 8 句池子）——插件直发不走模型、零 token；概率可调（普通戳默认 8%、戳一戳默认 25%，戳是明确动作给高些）、全局冷却（默认 10 分钟）、语料池全部可配；群里围观闲聊不触发，只回应戳她的人
- **临时清醒 → 智能回睡**（夜间被叫醒后的完整生命周期）：
  - 被叫醒进入"没醒透"状态：消息正常回复，窗口期间每轮注入"还带着困意"状态行（语气不会一两轮就恢复正常）
  - 回睡不做死板倒计时：清醒满最短时长（默认 40 分钟）后开始观察，"对她说的话"**全渠道合并**冷场（默认 5 分钟，私聊/群@她/叫应答昵称都算在说话，围观闲聊不算）→ 回睡；90 分钟上限兜底强制回睡
  - 冷场防误判：昵称前是不/没/别/非/莫不算（"不吃肥鱼了"）；引用消息里的昵称是转述不算
  - 撞原定起床时刻（含睡眠债顺延后）→ 直接彻底醒，不再回睡
  - **睡眠债**：临时清醒 N 分钟 → 起床顺延 N×50%（比例可配），"被你吵醒那么久，多睡会儿不过分吧"
  - **回睡告别语**：只发叫醒来源会话；首选 LLM 临场生成（每次不一样，失败/超时回落 14 句语料池：傲娇/困倦/不耐烦/温柔四款可编辑）；由回睡定时器主动发送，不依赖任何入站事件
  - 午睡被叫醒=直接转清醒，不进临时清醒（本来就只眯一会儿）
- **午睡补偿 + 没睡醒**（熬夜次日的午后彩蛋，v0.5.0）：
  - 资格：昨晚失眠、或入睡晚于赖床阈值；触发概率默认 40% 可配
  - 午睡时刻在 13:00~15:00 间随机、时长 15~30 分钟随机——守门/缓冲/叫醒频道全按夜间那套，醒来不重抽今晚作息
  - "没睡醒"状态行白天每轮注入（临时注入不进历史）：抽中午睡=蔫到午睡结束，没抽中=蔫到 17:00；说话更蔫、句子更短由人设自由发挥
  - 起床收口抖动：撞"最早起床"地板时 +0~10 分钟、顶"最晚起床"硬顶时 −5~0 分钟随机——消除"连续几晚精确整点醒"的闹钟感，且不破坏"不早于地板/不晚于硬顶"承诺
- **配置校验**：数值类超范围/跨字段矛盾自动回落默认值 + WARNING（跨午夜时间先归一化再校验）；提示词模板自由编辑不做校验

- **休息日体系**（v0.6.0，中国语境周末≠休息日）：
  - 判定链五层短路：补充工作日 > 补充休息日 > 法定节假日 > 调休补班 > 常规周（休息制度下拉 1=单休/2=双休/3=大小周，大小周按 ISO 周奇偶交替）
  - 节假日数据来自 chinese-calendar（缺包/年度过期自动降级纯星期判定+日志提醒），手动补充名单零依赖兜底
  - 「休息日独立作息」开关（默认关=每天同一套）：开启后醒来日是休息日的夜走休息日组——入睡窗/起床窗留空=自动（工作日窗+30~60 随机熬夜偏移 / +赖床加成），时长/赖床/失眠/午睡沿用全局
- **固定模式 2.0（上班族版）**（v0.6.0）：固定时刻+双端小毛边（入睡 0~20 分钟、起床 0~15 分钟每日随机，按日落盘），失眠/赖床保持关
- **/作息分布 [休息日]**（v0.6.0，管理员）：按当前配置模拟 100 晚出入睡/醒来直方图+统计——改完配置 3 秒看效果，不用猜
- **表演指引注入**（v0.6.0）：醒来首轮随夜间消息临时注入人格无关的表演参考（翻消息挑着回、被问才说作息、深夜倾诉优先），模板可编辑
- **LLM 闸门**（v0.7.0，安全修复）：堵住"必回后门"——`/` 开头但没命中任何指令的文本（如 `/你好`）原本会被框架当唤醒消息 100% 必回、绕过读空气概率，睡觉时更是穿帮。现在非管理员一律静默；真指令、链接解析全天不受影响
- **管理员暗门**（v0.7.0，默认开）：管理员发 `/` + 随便什么仍能跟她说话——白天正常回，她睡着时按"半梦半醒说梦话"演出回（状态行模板可改）
- **夜间裸链接放行**（v0.7.0，默认开）：她睡着时群里发裸链接（不带 `/`）也放行给链接解析直回卡片，进不了对话
- **自回显跳过**（v0.7.0）：她睡着时自己发出的工具产物（解析卡等）不再被当成"夜间收到的消息"缓冲，晨间冲刷不再出现发给自己的幽灵条目
- **午睡豁免两旋钮**（v0.7.0）：①休息日免午睡——醒来日是休息日的熬夜夜不午睡、白天不蔫（周末睡到饱不用补觉）；②睡够 X 小时免午睡——实际睡眠≥X 则当日不午睡不蔫（0=关），管所有日子

## 算法速览：一晚是怎么抽出来的（工作日 vs 休息日）

从入睡到醒来一共六步，"休息日"只改其中三步；简单配置模式只是把详细参数先自动派生好，链路完全一样：

1. **判夜**：按「醒来那天」是不是休息日选参数组。判定链=补充工作日名单 > 补充休息日名单 > 法定节假日/调休（chinese-calendar，缺包自动降级纯星期）> 常规周（1 单休 / 2 双休 / 3 大小周）。**周日晚（醒周一）永远是工作日夜**——周五周六熬夜、周日收心，是按真人习惯定的。
2. **入睡**：以「基准入睡点」为峰正态抽一次（波动宽度=窗宽÷4），被「入睡窗·最早/最晚」两把剪刀夹住；按「失眠概率」抽中则改在 [最晚入睡, 失眠上限] 均匀抽。**休息日夜**：填了独立入睡窗 → 整套换窗（基准=最早+窗宽×0.55、赖床阈值=窗末−30）；留空 → 工作日入睡窗整体 +30~60 分钟随机熬夜偏移。
3. **时长**：按「基准睡眠时长 ± 波动」正态抽一次。
4. **加成**（叠在时长之上、不是替换）：休息日夜叠「周末加成」（下限~上限均匀抽一次，默认 30~90 分钟）；「赖床掷骰」掷中再叠「赖床加成」——入睡晚于赖床阈值起算，基础概率 + 每再晚 30 分钟递增，失眠夜必中，早睡夜也有小概率偶发。
5. **醒来** = 入睡 + 时长 + 加成们，夹进「起床窗·最早/硬顶」（休息日填了独立起床窗则用之，再赖也不会晚过硬顶）；随后收口抖动——撞地板 +0~10 分钟、顶硬顶 −5~0 分钟，消掉整点醒来的机械感。
6. **白天**：失眠或熬夜夜 → 次日"没睡醒"蔫到 17:00；13:00~15:00 掷「午睡概率」眯 15~30 分钟。两项都可被豁免：「休息日免午睡」（周末睡到饱不补觉）、「睡够 X 小时免午睡」——豁免时午睡和蔫一并免掉。

改完配置想直观验证：`/作息分布` 和 `/作息分布 休息日` 各跑一遍，当前配置下 100 晚的入睡/醒来直方图立即出结果，不用等真实日子。

## 配置速查（面板字段怎么填）

**只想填 5 项：** 打开「基础 → 简单配置」，去「⚡ 快速设定」填 5 个旋钮——绝对最早睡觉 / 入睡可接受范围 / 绝对最晚起床 / 赖床最高概率 / 赖床可接受时间。入睡窗、入睡基准、起床边界、赖床阈值与概率爬坡等 12 项全部自动派生（构造上不可能互相矛盾），周末加成自动被"最晚起床"收口。睡眠时长与波动、周末幅度、失眠概率、早睡偶发赖床、睡眠债折算这 5 类仍去详细区调（字段说明带"仍生效"标记；被派生取代的项带 ⚠️ 标记）。关掉简单配置则详细区逐项全效，两种模式随时切换。

**详细模式核心概念——基准/最早/最晚是"众数 + 两把剪刀"：**
入睡时刻不是在最早~最晚之间均匀乱抽，而是**以基准入睡点为峰的近正态分布**，最早/最晚只是两端的硬剪刀（抽出去的裁回来）。同一个窗 23:00~01:30：基准 00:00 = 大多数夜熬到 0 点附近才睡、偶尔早困；基准 23:30 = 习惯早睡、偶尔拖到 0 点后。想"窗口内不偏不倚"就把基准填成窗口正中间。波动宽度由窗宽自动推导（窗宽÷4），基准只挪峰的位置、不改变散布。

**临时清醒的三段闸门**（相关三项的关系）：被叫醒后先撑满「最短清醒时长」（这期间不看冷场，防"半夜戳一下秒睡回去"太假）→ 之后冷场满「冷场判定」就回睡（任何渠道的互动都重置计时，私聊在聊=群里也不算冷场）→ 到「最长清醒上限」无论如何强制回睡。
